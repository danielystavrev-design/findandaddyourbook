Setting up accounts for your site (one-time, for the site owner)
  1. Create a free project at console.firebase.google.com.
  2. Build → Authentication → Get started, enable the Email/Password sign-in method.
  3. Build → Firestore Database → Create database, then set its security rules so each account only reaches its own books (see the comment in app.js for the exact rules to paste).
  4. Project settings → your app → copy the firebaseConfig object, and paste it into firebaseConfig near the top of app.js.
  5. Re-deploy the site. Everyone who signs up will then have their own private collection.
